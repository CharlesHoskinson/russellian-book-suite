# Validation bundle — Russellian voice calibration (polemic mode)

This bundle is the evidence for Task 6 of the "Russellian Voice Calibration"
change: a demonstration that the revised `polemic` system prompt yields prose at
least as clean, under the russellian-style linters, as the pre-change prompt.

## What was tested

The `russellian-style` skill ships a `polemic`-mode system prompt at
`skills/russellian-style/assets/system-prompts/polemic.md`. The change under test
**appends** a `# Calibration and planning` section to that prompt: silent
paragraph-motion planning (concession → example → distinction → consequence → turn),
mode-matched corpus anchors, and a single Russell touchstone illustrating compression
of a reversal into an antithesis.

To validate the change, two essays of the same title — "On the Absurdities of
Artificial Intelligences Governing Human Passions" — were drafted, one under each
prompt version, then linted with the same twelve linters:

- `baseline-polemic.md` — written under the **baseline** prompt: the polemic prompt
  with the `# Calibration and planning` section removed.
- `candidate-polemic.md` — written under the **candidate** prompt: the current
  on-disk `polemic.md` (baseline + calibration), with the calibration discipline
  actually applied.

## Prompt version under test

The candidate prompt is the `polemic.md` as of:

- `cdd7bb5` — "Add voice calibration to russellian-style mode prompts"
- `cfa3a5d` — "Correct calibration anchor wording in two mode prompts"

These two commits together produce the `# Calibration and planning` section being
validated. The baseline prompt is that same file with the appended section deleted
(reconstructed for this test; the baseline is not a separate committed file).

## Verdict

**PASS.** The candidate essay produced no more linter findings than the baseline on
any of the twelve linters, and strictly fewer on six of them (total findings 7 vs
13). The revised prompt does not degrade prose cleanliness; on this sample it
improves it. Full per-linter numbers and the revision history are in
[`lint-results.md`](./lint-results.md).

## Caveats

- **Single-sample evidence.** This is a two-essay comparison on one title, not a
  statistical corpus study. It demonstrates the calibrated prompt can match or beat
  the baseline under the linters; it does not measure an average effect size.
- **Author-in-the-loop.** Both essays were drafted by the same agent applying the
  respective prompts, not generated by an isolated model run of each prompt. The
  candidate draft was revised once to satisfy the acceptance rule (candidate ≤
  baseline on every linter); only the essay was changed, never the linters. See
  `lint-results.md` for what changed.
- **Linter severity.** Several of these linters (ai_vocabulary, ai_staccato,
  burstiness, paragraph_motion, concrete_instance_density, epistemic_precision) emit
  at advisory severity in v1 and do not gate a build by themselves; the counts here
  are still used as the comparison metric.
- **spaCy environment.** spaCy + `en_core_web_sm` were available, so all twelve
  linters ran. Reproducing this requires installing `click`/`typer` alongside the
  `[ci]` extra before `spacy download` (the `[ci]` extra alone omits the CLI deps).
