# Suite-wide end-to-end review — 2026-05-29

**Scope:** the whole repository — seven core skills, `neurosym-forge`, `tools/`, `ci/`, the `verifiers/` Rust + ClojureScript layer, and the CI/CD system.
**Method:** thirteen review shards (nine subsystem agents, two domain-tuned language agents for the Rust verifier core and the ClojureScript logic-translation layer, two cross-cutting agents for CI/CD and security). Every finding then passed an independent adversarial-verify step that read the cited code and defaulted to rejection; only findings that survived appear here.
**Boundary:** static analysis on Windows. The Nix/Linux CI and the full test suite were not run. Findings that depend on runtime behaviour are listed separately in [uncertain-and-runtime.md](uncertain-and-runtime.md), not asserted here.
**Spec:** [`docs/superpowers/specs/2026-05-29-suite-wide-end-to-end-review-design.md`](../../superpowers/specs/2026-05-29-suite-wide-end-to-end-review-design.md).

## What matters most

**The verifier chain does not verify.** Five of the seven criticals lie on the path from a ClojureScript orchestrator to the Rust native addon, and they compound. The orchestrator's `nl_to_fol` emits nested `{:kind :expression …}` trees while the Rust `smt.rs` dispatches on flat `:subject/:predicate/:value` atoms, so a translated formula matches nothing the solver looks at. `phases/verify` ships a bare vector where `parse_formulas` demands a top-level `{:atoms […]}` map, so the call errors before any solving. In `kg.rs`, `ingest_and_summarize` queries `claim/load-bearing` and `claim/posterior` relations that `build_db` never creates, so the default knowledge-graph-enabled build returns `Err` on every call. The `adsc-clinical` copy of `smt.rs` is missing the `Edn::UInt` arm its `bermuda` twin has, so plain integer constraint values fall through to `_ => continue` and are silently dropped — a false `sat`. Independently, the two language agents reached the bridge from opposite sides and corroborated the same contract mismatch. The practical consequence: the optional neurosym-forge satisfiability gate cannot today contribute a real verdict against the native addon, and the two near-duplicate verifier instances have already drifted apart.

**The release gate under-blocks.** `book-qa`'s sentinel treats only D1–D8 as hard-fail, so the critical reasoning defects D9 (paragraph-orphan), D10 (transitive-contradiction), D11 (failed-entailment) and D13 (verification-unsat) — written into `defects.json` by `lint_artifact` — are routed to the non-blocking soft gate. They neither block release nor reach the healer. The component linter (`lint_artifact.main`) exits non-zero on these, but the aggregating sentinel that is the documented final gate does not, so the suite's strongest prose gate is quieter than its own taxonomy claims.

**Branch protection points at jobs that no longer exist.** Both `docs/operations/branch-protection.md` and `scripts/ruleset-apply.sh` require status contexts (`lint`, `scaffold-bake`, `regression (sprint-5)`, `verifier (bermuda)`, `verifier (osmotic-pressure)`) that `ci.yml` stopped emitting when it collapsed to a single `nix preflight` job plus `cargo-test` legs. Applying that ruleset configures GitHub to wait forever on checks that never post — blocking every merge, or, if protection is not enforced, gating on nothing.

**Supply-chain hygiene is thin.** Every third-party Action is pinned to a mutable tag rather than a commit SHA; the `no-direct-http` import-linter contract has empty `root_packages` and `source_modules`, so it analyses nothing and passes vacuously; and the `no_shadow_writes` guard monkeypatches only `builtins.open`, missing the `pathlib` `write_text`/`write_bytes` calls that most of the suite actually uses.

A reasonable fix order: the verifier-chain criticals and the `book-qa` gate routing first (they make two correctness gates weaker than they read), then the branch-protection drift (it can wedge merges), then the security items (cheap, high-leverage), then the long tail of high/medium correctness findings per skill.
