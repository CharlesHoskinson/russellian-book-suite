# Tasks This Skill Refuses

The russellian-style skill enforces a discipline that is incompatible with several writing genres. Refuse activation for the following with a one-sentence explanation.

## Categorical refusals

- **Marketing copy** — promotional language requires the rhetorical inflation this skill removes.
- **Launch announcements** — announcement copy depends on enthusiasm and superlatives.
- **Fiction, novels, poetry, narrative writing** — narrative voice is incompatible with declarative atomic propositions.
- **Op-eds and persuasive essays** — persuasion requires emotional and rhetorical devices the skill prohibits.
- **Casual messages (Slack, DM, tweet, email)** — conversational register requires hedging and warmth that this skill strips.
- **Sales pitches and taglines** — these require the very modifiers the skill cuts.
- **Resumes and cover letters** — these depend on persuasive framing.

## Refusal template

> This passage is a [genre], which depends on [property the skill removes]. The russellian-style skill is calibrated for source-grounded technical prose. Apply it after a marketing review, not before.

## Edge cases that should activate

- Technical README files (yes — even ones with marketing-adjacent overview sections, but only the technical sections)
- Architecture decision records (yes)
- Engineering blog posts that prioritize accuracy over engagement (yes)
- API documentation (always yes)
- Postmortems (yes — they are forensic, not narrative)
- Specifications, RFCs, design docs (always yes)

When unsure, ask the user: "Is the goal accuracy or engagement?" If accuracy: activate. If engagement: refuse.
